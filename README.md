# Software Engineer Portfolio

A modern, responsive portfolio website built with React, Vite, and Framer Motion.

## 🚀 Live Demo
**[View Portfolio](https://AkashRajSarraf.github.io/Portfolio/)**

## 🛠 Tech Stack
- **React.js**: Frontend library
- **Vite**: Build tool for fast development
- **Framer Motion**: For animations and transitions
- **CSS3**: Custom styling and responsive design
- **FontAwesome**: For icons

## 📦 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/AkashRajSarraf/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run local development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages**
   ```bash
   npm run deploy
   ```

## ✨ Features
- Interactive Hero Section with 3D-like effects
- Smooth scrolling and navigation
- Responsive design for all devices
- Dynamic project showcase
- Animated skill bars and cards
